Task 1: House Price Prediction Model
This project involves building a machine learning model to predict housing prices using the California Housing dataset.

Key Deliverables:
Jupyter Notebook: Full Python implementation of the ML workflow.

Technical Report: Analysis of EDA and model performance.

Presentation: Summary of findings and evaluation metrics.

Performance Metrics:
Algorithm: Linear Regression.

Metrics used: Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R-squared (R²).
